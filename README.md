# Pokémon USB Hub

A custom Pokémon-themed USB hub PCB project, designed as a Great Ball-shaped board.

## Project Contents

- `SCH.pdf` — schematic export
- `PCB.pdf` — PCB layout export
- `Gerber.zip` — manufacturing files
- `PickAndPlace.xlsx` — assembly placement data
- `JOURNAL.md` — design/build log with screenshots

## About the Design

This project is a multi-port USB hub board with a themed mechanical/visual design:

- Great Ball-inspired board outline
- USB-C input plus multiple USB-A ports
- Pokémon-themed silkscreen artwork
- Decorative copper + soldermask visual effects

## Manufacturing Notes

1. Upload `Gerber.zip` to your PCB manufacturer.
2. Use `PickAndPlace.xlsx` for SMT assembly support.
3. Verify orientation and connector footprints against `SCH.pdf` and `PCB.pdf` before ordering.
