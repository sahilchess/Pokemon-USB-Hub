# Pokémon USB Hub (Great Ball PCB)

A custom Pokémon-themed USB hub PCB shaped like a **Great Ball**, with decorative artwork and a circular board layout.

## Repository Contents

- `SCH.pdf` — schematic export
- `PCB.pdf` — PCB layout export
- `Gerber.zip` — manufacturing files
- `PickAndPlace.xlsx` — component placement file
- `JOURNAL.md` — design/build log with screenshots

## Project Notes

- Version: **v1.0.0**
- Theme/artwork includes Pikachu, Rayquaza, Mewtwo, and Charizard.
- The board was designed as a circular, Great Ball-style USB hub.

## Getting Started

1. Review `SCH.pdf` and `PCB.pdf` for design details.
2. Use `Gerber.zip` to order PCB fabrication.
3. Use `PickAndPlace.xlsx` for assembly/reference during population.
4. See `JOURNAL.md` for process notes and progress images.
